# Pointory

Pointory 是一款使用 Rust 和 Slint 构建的原生桌面鼠标自动点击工具。主界面只显示任务列表，添加、编辑和删除确认均通过弹窗完成。

## 功能特点

- **默认鼠标连点器**：固定保留首行任务，跟随鼠标持续点击左键，默认间隔 **1000 毫秒**、快捷键 **F1**；编辑弹窗只提供间隔和快捷键。
- **自定义任务**：通过“添加任务”弹窗创建任务，列表直接显示按键、位置、间隔、次数、颜色条件、快捷键、状态和点击数；通过每行按钮运行、停止、编辑或删除。
- **点击位置**：跟随当前鼠标位置，或通过 **F8** 取点并使用固定屏幕坐标；像素放大镜可实时预览鼠标周围的画面。
- **颜色检测**：可设置仅在目标像素颜色匹配时点击，颜色容差分别作用于红、绿、蓝三个通道。
- **执行节奏**：默认点击间隔为 1,000 毫秒，支持固定间隔或指定范围内的随机间隔。
- **按键与次数**：支持鼠标左键、右键、中键，可设置点击次数或持续运行。
- **快捷键与批量执行**：任务快捷键用于开始 / 停止；“加入批量运行”决定自定义任务是否参与批量启动。重复、保留或系统占用的快捷键会提示错误。
- **全部停止**：通过界面中的“全部停止”或 **Ctrl + Alt + Esc** 停止所有运行中的任务。
- **可靠保存**：完整校验后保存，取消编辑不影响任务；使用原子替换保护原文件，单实例锁防止多个窗口覆盖配置。

## 构建与运行

日常只编译 Windows。安装最新 Rust 稳定版 x64 MSVC 工具链与 PowerShell 7，在项目根目录执行：

```powershell
pwsh -File scripts/build-windows.ps1
```

脚本依次检查格式、运行测试、编译 Windows 并打包。发布包为 `dist/Pointory-0.2.0-Windows-x64.zip`，同目录提供对应 `.sha256` 校验文件。

开发时也可执行：

```sh
cargo run --release --locked
```

可执行文件位于 `target/release/pointory.exe`。Linux 实现同步维护，仅在明确需要时在 Linux 环境构建和验证。

## 使用说明

1. 直接点击默认“鼠标连点器”的“运行”，或按 **F1** 开始 / 停止；点击“编辑”修改间隔和快捷键。
2. 如需更复杂的点击行为，点击“添加任务”，在弹窗中设置名称、鼠标按键、间隔和次数。
3. 如需固定位置，点击“取点”，将鼠标移至目标后按 **F8** 确认；也可勾选固定位置并手填坐标。未固定时跟随当前鼠标。
4. 如需颜色条件，点击“吸取颜色”，移至目标像素后按 **F8** 确认，或手填颜色与容差。进入取样会先停止点击任务。
5. 按需设置快捷键和“加入批量运行”，点击“添加任务”或“保存”；点击“取消”或按 Esc 放弃草稿。
6. 使用每行“运行 / 停止”按钮或任务快捷键操作。“批量运行”只启动已加入批量且尚未运行的任务。编辑前需停止该任务，编辑期间其他运行中任务仍可用快捷键停止。

最长间隔设为 `0` 时使用固定间隔；大于最短间隔时，在两者之间随机取值。点击次数设为 `0` 时持续运行，直到手动停止。

程序启动后不会自动执行点击任务，需通过运行按钮或任务快捷键显式启动。需要停止全部任务时，可按 **Ctrl + Alt + Esc**。

## 平台说明

- **Linux**：全局快捷键和屏幕截图可能需要 X11 会话及桌面访问权限；Wayland 合成器可能限制全局输入和像素采样。
- **Windows**：当前默认构建和验收平台，支持虚拟桌面的负坐标与副屏定位。

## 配置文件

0.2.0 使用严格的新配置格式，保存至系统用户配置目录下的 `Pointory/settings.json`，再次启动时自动读取。旧版任务配置不读取、不迁移。Windows 通常位于 `%APPDATA%/Pointory/settings.json`，Linux 通常位于 `~/.config/Pointory/settings.json`。

损坏或不支持的配置会显示错误并阻止覆盖；修正或移走该文件后再保存。`instance.lock` 用于单实例保护，退出时由操作系统释放锁，文件保留。

版本变更见 [CHANGELOG.md](CHANGELOG.md)。

开发验证时可用环境变量 `POINTORY_CONFIG_DIR` 指定独立配置目录，避免修改日常任务数据。
