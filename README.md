# Pointory

Pointory 是一款使用 Rust 和 Slint 构建的原生桌面鼠标自动点击工具，支持独立任务、固定坐标、颜色检测、随机间隔、任务快捷键和批量执行。

## 功能特点

- **独立任务**：创建、重命名、保存和删除点击任务，每个任务单独保存执行设置。
- **点击位置**：跟随当前鼠标位置，或通过 **F8** 取点并使用固定屏幕坐标；像素放大镜可实时预览鼠标周围的画面。
- **颜色检测**：可设置仅在目标像素颜色匹配时点击，颜色容差分别作用于红、绿、蓝三个通道。
- **执行节奏**：默认点击间隔为 1,000 毫秒，支持固定间隔或指定范围内的随机间隔。
- **按键与次数**：支持鼠标左键、右键、中键，可设置点击次数或持续运行。
- **快捷键与批量执行**：每个任务可配置全局快捷键；“加入全局批量执行”仅决定是否参与批量运行，不影响单独运行按钮和任务快捷键。
- **全部停止**：通过界面中的“全部停止”或 **Ctrl + Alt + Esc** 停止所有运行中的任务。
- **配置保存**：任务设置保存在操作系统的用户配置目录中。

## 构建与运行

安装 Rust 稳定版工具链，在项目根目录执行：

```sh
cargo run --release
```

如需仅构建可执行文件：

```sh
cargo build --release
```

构建产物位于 `target/release/` 目录。

## 使用说明

1. 新建或选择任务，设置任务名称、鼠标按键、点击间隔和点击次数。
2. 如需固定位置，点击“取点”，将鼠标移至目标位置后按 **F8** 确认；未设置固定位置时，点击将跟随当前鼠标。
3. 如需检测颜色，点击“吸取颜色”，移至目标像素后按 **F8** 确认，并设置颜色容差。
4. 按需设置任务快捷键或勾选“加入全局批量执行”，然后保存设置。
5. 单独运行任务，或使用“执行批量任务”运行已勾选的任务。

最长间隔设为 `0` 时使用固定间隔；大于最短间隔时，在两者之间随机取值。点击次数设为 `0` 时持续运行，直到手动停止。

程序启动后不会自动执行点击任务，需通过运行按钮或任务快捷键显式启动。需要停止全部任务时，可按 **Ctrl + Alt + Esc**。

## 平台说明

- **Linux**：全局快捷键和屏幕截图可能需要 X11 会话及桌面访问权限；Wayland 合成器可能限制全局输入和像素采样。
- **macOS**：系统可能要求授予辅助功能和屏幕录制权限。

## 配置文件

任务设置保存至系统用户配置目录下的 `Pointory/tasks.json`，再次启动时自动读取。
