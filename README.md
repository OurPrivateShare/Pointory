# Pointory

Pointory 是一款使用 Rust 和 Slint 构建的原生桌面鼠标自动点击工具。主界面只显示任务列表，添加、编辑和删除确认均通过弹窗完成。

## 功能特点

- **默认鼠标连点器**：固定保留首行任务，跟随鼠标持续点击左键，默认间隔 **1000 毫秒**、快捷键 **F1**；编辑弹窗只提供间隔和快捷键。
- **自定义任务**：全部使用固定坐标，必须通过“位置取点”或手工输入 X、Y 坐标设置点击位置后才能保存。列表直接显示基本设置、状态和点击数，每行提供运行、停止、编辑或删除。
- **清晰的任务表格**：顶部集中显示任务总数、运行数量与保存状态；支持按名称、坐标、快捷键或颜色搜索，筛选不改变任务的运行和批量设置。
- **分区任务设置**：基本信息、执行节奏、固定位置和颜色条件集中在弹窗中；随机间隔与点击次数使用明确开关，支持 **Ctrl + Enter** 保存。
- **屏幕取样**：“位置取点”和“吸取颜色”会自动最小化主窗口；放大镜浮窗跟随光标，鼠标左键确认、Esc 取消，随后恢复编辑弹窗。确认点击不会传递给目标应用。
- **颜色检测**：可设置仅在目标像素颜色匹配时点击，颜色容差分别作用于红、绿、蓝三个通道。
- **执行节奏**：默认点击间隔为 1,000 毫秒，支持固定间隔或指定范围内的随机间隔。
- **按键与次数**：支持鼠标左键、右键、中键，可设置点击次数或持续运行。
- **快捷键与批量执行**：任务快捷键用于开始 / 停止；“加入批量运行”决定自定义任务是否参与批量启动。重复、保留或系统占用的快捷键会提示错误。
- **全部停止**：通过界面中的“全部停止”或 **Ctrl + Alt + Esc** 停止所有运行中的任务。
- **便携保存**：配置保存在程序旁的 `config.json`；退出后移动整个软件文件夹，任务设置随软件一起移动。完整校验后原子保存，取消编辑不影响任务。
- **系统主题**：使用系统默认主题、按钮和输入框，随系统的亮色或深色设置显示。
- **统一图标**：蓝色鼠标指针与点击波纹图标用于应用界面、窗口和 Windows 程序文件。

## 构建与运行

日常只编译 Windows。安装最新 Rust 稳定版 x64 MSVC 工具链与 PowerShell 7，在项目根目录执行：

```powershell
pwsh -File scripts/build-windows.ps1
```

脚本依次检查格式、运行测试、编译 Windows 并打包。发布包为 `dist/Pointory-0.5.0-Windows-x64.zip`，同目录提供对应 `.sha256` 校验文件。重新打包只包含程序和说明文档，不包含本地任务配置。Windows 构建需安装 Windows SDK，构建脚本会调用 `rc.exe` 嵌入程序图标和版本资源。

开发时也可执行：

```sh
cargo run --release --locked
```

可执行文件位于 `target/release/pointory.exe`。Linux 实现同步维护，仅在明确需要时在 Linux 环境构建和验证。

Windows 开发时可生成主界面及设置弹窗的布局预览，不会启动点击任务或操作桌面：

```powershell
cargo test --release --locked ui_preview::render_ui_previews -- --ignored --nocapture
```

预览图片位于 `target/validation/ui-0.5.0/`，覆盖普通与最小窗口、默认任务、自定义任务、校验错误、删除确认和搜索空状态；删除弹窗还会验证内容不受底层变化影响。

## 使用说明

1. 直接点击默认“鼠标连点器”的“运行”，或按 **F1** 开始 / 停止；点击“编辑”修改间隔和快捷键。
2. 如需更复杂的点击行为，点击“添加任务”，在弹窗中设置名称、鼠标按键、间隔和次数。
3. 点击“位置取点”，等待主窗口最小化，将鼠标移至目标并点击左键确认；也可手工输入坐标。仅默认“鼠标连点器”跟随鼠标。
4. 如需颜色条件，点击“吸取颜色”，主窗口最小化后移至目标像素并点击左键确认，或手填颜色与容差。进入取样会先停止点击任务；按 Esc 可取消。
5. 按需设置快捷键和“加入批量运行”，点击“添加任务”或“保存”；点击“取消”或按 Esc 放弃草稿。
6. 使用每行“运行 / 停止”按钮或任务快捷键操作。“批量运行”只启动已加入批量且尚未运行的任务。编辑前需停止该任务，编辑期间其他运行中任务仍可用快捷键停止。

默认使用固定间隔并持续点击。打开“随机间隔”后设置最短、最长间隔；打开“限制点击次数”后输入正整数，到达次数后自动停止。关闭开关时，对应的隐藏输入不会影响保存。

程序启动后不会自动执行点击任务，需通过运行按钮或任务快捷键显式启动。需要停止全部任务时，可按 **Ctrl + Alt + Esc**。

## 平台说明

- **Linux**：全桌面左键取样需要 X11 会话及桌面访问权限；Wayland 下可手工输入固定坐标和颜色。Linux 实现同步维护，本次未编译或进行 Linux 桌面验收。
- **Windows**：当前默认构建和验收平台，支持虚拟桌面的负坐标与副屏定位。

## 配置文件

任务设置固定保存在运行程序所在目录的 `config.json`，与启动时的工作目录无关。解压到可写文件夹后运行，保存任务时自动生成配置。退出程序后，将整个文件夹复制或移动即可保留任务。

不读取用户配置目录或环境变量指定的位置，不迁移旧配置，不提供旧版本兼容。目录不可写、配置损坏或格式不支持时会明确报错，不会悄悄改存其他目录或覆盖损坏的原文件。

同一软件目录只允许一个实例运行。Windows 使用按目录区分的系统互斥锁；Linux 使用同目录的 `instance.lock`，退出时由操作系统释放锁。

版本变更见 [CHANGELOG.md](CHANGELOG.md)。

开发验证需要隔离任务数据时，将测试可执行文件复制到单独的可写目录运行。
